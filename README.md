# OpenApps HQ Homebrew tap

Casks for the official builds of OpenApps HQ Mac apps.

```sh
brew install --cask openappshq/tap/openreaction
brew install --cask openappshq/tap/openklack
```

Each app installs into `~/Applications`, needs no admin password, and updates with `brew upgrade --cask <app>` (or from the app's own Settings → Updates).

The casks here are written by the release workflows in [openappshq/openapps](https://github.com/openappshq/openapps); see its `RELEASES.md`.
